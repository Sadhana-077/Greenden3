# Greenden – Responsive Plant Shop Website

## Project Overview

Greenden is a responsive and modern plant shop website developed using **HTML5** and **Tailwind CSS**. The website provides a clean and user-friendly interface for browsing plant collections, exploring best-selling products, and contacting the store.

## Features

* Responsive design for mobile, tablet, and desktop
* Modern user interface built with Tailwind CSS
* Responsive navigation bar

## Responsive Design

The website is fully responsive and adapts to:

* Mobile devices
* Tablets
* Laptops
* Desktop screens

Tailwind CSS responsive utility classes are used to ensure a consistent user experience across different screen sizes.
